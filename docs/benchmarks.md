# Benchmark methodology

Two compiler candidates were timed on the locked Linux x86-64 cohort and dropped. Neither is a qualified faster-rebuild result. The original stage-2 package contains the unpatched compiler and patched Cargo. `qualification/COMPAT.md` records the suite and ecosystem comparison, not a budget pass. The outliner plus opt-level 0 pre-link probe rebuilt ripgrep in 16.74s against a 19.14s control leaf, with peak RSS about 2.11 times the control. The opt-level 1 pre-link probe, without the outliner, measured leaf ratios 0.951 (ripgrep), 1.016 (syn), and 1.000 (regex), geometric mean 0.989. The frozen budgets want a leaf geometric mean of at most 0.80 and peak RSS of at most 1.10. The detail, including the LLVM pass split, is in `qualification/CANDIDATE.md`. Timings from earlier versions of fRust describe a different toolchain architecture.

Compare fRust with the same upstream Rust and Cargo revision, under the same optimization, debug, panic, target, codegen-unit and linker settings. Include an upstream release baseline with incremental compilation and full LTO explicitly enabled whenever fRust uses those settings. Record the actual compiler and linker invocations.

Report clean builds with cold artifacts, Cargo no-op builds, local implementation edits, wider dependency changes and native relinks separately. For source edits, verify the edited target ran and log which phases did fresh work. Verify the edited result against a fresh build before counting reuse as a win. Record elapsed time, tail latency, peak memory and disk use on the stated host.

Measure runtime and executable size independently. Compare equivalent stripped artifacts and record debug-symbol size separately. Publish the command, inputs, toolchain versions, host details, seed state and repeat measurements for any public performance claim.

The post-optimization codegen cache and RELR are independent opt-in experiments in the source patch. Keep them isolated from qualification targets. On the locked cohort, ripgrep's unused-local leaf preserved its optimized IR, syn and regex exercised library builds, and fd's required miss regressed. Use that evidence to distinguish machine emission, whole-program optimization, and library rebuilds. See the [candidate ledger](../qualification/CANDIDATE.md).
