# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the work. Harassment and personal attacks are not
tolerated. Maintainers may edit or remove contributions and restrict participation that breaks these expectations.

Report problems privately by opening a [private security advisory](https://github.com/Seggys116/frust/security/advisories/new)
or by contacting the maintainer, [@Seggys116](https://github.com/Seggys116), through GitHub.
